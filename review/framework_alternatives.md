# 분류 틀 대안 비교와 최적안 (2026-10-11)

## 최적안 = D 주축 + A의 기능 축 + B의 차원 용어 + 제도환경 교차

- 주축(절 구조): 단계 S1~S5. 각 절 머리에 그 단계가 재는 유동성 차원(즉시성·비용·깊이)을 B의 용어로 정의.
- 부축(절 내부): 기능 F1 정의·구축 / F2 측정 쟁점 / F3 선행성·관계. 처음 안의 "타당성"과 "선행성"은 학생 코딩에서 갈리기 어려워 합쳤다.
- 교차: 제도환경 MLS / 비MLS / 경매. 증거지도 253편은 단계×환경 건수의 분모.

이 틀이 주는 검정 가능한 명제: **상류 단계 지표의 선행 길이가 더 길다.** 표 4(단계 순 선행성 증거표)가 이를 검토한다.

## 위험과 보완
- 단계 5개가 많다고 판단되면 S1·S2를 "상류"로 합쳐 4단계로 줄여도 논리는 유지된다.
- 복합 지수(S5)는 단계를 가로지르므로 "집계 상태"를 별도 단계로 두어 억지 배정을 피했다.
- 초기 코드는 Claude가 달았고(`review/synthesis_set.csv`), 추출 시 학생이 확인한다. 바뀐 건수와 κ를 논문 방법 절에 보고한다.
