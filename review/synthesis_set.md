# 종합 대상 148편 — 연구책임자 승인용 목록 (2026-10-10)

기준(프로토콜 §4.4): 유동성 지표가 연구의 **대상**인 논문만. C1 = 지표를 정의·측정·구축·검증하거나 측정 대안을 비교 / C2 = 지표의 선행성·예측력·정보내용을 검정. 지표를 다른 요인의 효과를 재는 결과변수로만 쓴 연구(어메니티·중개사·정책·충격 등)는 증거지도(map)로, 이론 모형은 배경(background)으로 분류했다.

**승인 방법**: 빼야 할 것은 행 앞에 `X`, 증거지도에서 넣어야 할 것은 `review/included_studies.csv`의 `scope` 열을 `synthesis`로 바꾼다. 수정이 끝나면 `python3 scripts/assign.py --out students/assignments.csv`로 배정표를 재생성한다.
