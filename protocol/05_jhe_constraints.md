## 3. 참고문헌

| 항목 | 규정 |
|---|---|
| 투고 시 | 양식 자유, **일관성만** 요구. 저자·제목·학술지·연도·권·쪽(또는 논문번호) 필수. DOI 포함 권장 |
| 게재 시 양식 | **번호형 [n]**, 본문 등장 순 번호. 저자명 언급 시에도 번호 병기: "Barnaby and Jones [8]". 학술지명 LTWA 약어 |
| 예 | `[1] J. van der Geer, T. Handgraaf, R.A. Lupton, The art of writing a scientific article, J. Sci. Commun. 163 (2020) 51–59. https://doi.org/...` |
| 실존 요구 | "Every reference included must correspond to a real, existing source." → `verify_citations.py` 통과 필수. `[미검증]` 항목은 투고 불가 |
| 프리프린트 | "preprint" 명시 + DOI. 게재본이 있으면 게재본으로 교체 |
| 데이터 인용 | `[dataset]` 접두 + 저장소·버전·영구식별자 |

> 번호형 양식이므로 **Zotero 스타일을 "Elsevier – Vancouver/numbered" 계열로 설정**하고, 집필 중에는 저자-연도로 쓰다가 최종 변환한다. 변환 시 본문의 "Knight (2002)" 형 서술은 "Knight [12]"로 바뀌므로 문장 구조를 미리 번호형에 맞춘다.

## 5. 우리 리뷰에 대한 함의

1. 데스크 리젹을 피하는 첫 문장: 이 리뷰가 "경제학적 질문"임을 초록 첫 문장에서 보인다 — 유동성 지표의 **정의 변형이 추정치를 바꾸는 측정 문제**.
2. Highlights 5줄은 사실상 결과 요약이므로 **추출이 끝난 뒤** 쓴다.
3. 데이터 기탁 요건은 체계적 리뷰에 유리하다. 선별 로그·추출 양식 자체가 기탁 데이터다.
4. AI 사용 선언은 투고 시 반드시 넣는다. 이 저장소의 프로토콜·검색식·양식 작업에 AI 도구를 사용했으므로 그 범위를 기술한다.
5. 참고문헌은 번호형이므로 60편 이상이면 본문 가독성이 떨어진다. 증거 표에 서지를 몰아넣고 본문 인용은 핵심만.
