## 2. 148편은 어떻게 골랐나

1. **찾기**: 5개 경로(Semantic Scholar, Crossref, 핵심 학술지 16종 전수, 인용 추적, OpenAlex)로 52,006건.
2. **중복 제거**: 37,104건.
3. **규칙 선별 → 한 편씩 읽기**: 제목·초록에 주택 맥락어와 유동성 지표어가 함께 있는 1,400건을 읽어 438편 통과.
4. **기준 적용**: "유동성 지표가 그 논문의 **연구 대상**이어야 한다." 지표를 정의·측정·구축한 논문(F1·F2)과 지표의 선행성을 검정한 논문(F3)만 남겼다 → **148편**. 홍수·학군·중개사·정책이 TOM이나 거래량에 미친 효과를 본 253편은 건수만 세는 증거지도로, 이론 모형 37편은 인용만 하는 배경으로 보냈다.
5. **교수 승인**(10/11) 후 프로토콜 동결(10/13, `protocol/FREEZE.md`).

자세한 숫자는 `review/prisma_flow.md`, 엑셀 '선별과정' 시트.

## 3. 분류 틀 — 논문마다 붙어 있는 세 코드

배정표의 `stage`·`function`·`regime` 열. 정리하면서 맞는지 확인하고, 다르면 양식 0절에 바꾼 코드와 이유를 적는다.

| 코드 | 뜻 | 148편 |
|---|---|---|
| S1 수요·관심 | 검색량, 뉴스·소비 심리 | 25 |
| S2 공급·호가 설정 | 신규 매물·재고·호가 수준·호가 지수 | 16 |
| S3 매칭 | TOM/DOM, 매각확률, 호가 인하 | 39 |
| S4 체결·가격 발견 | 거래량·회전율, sale-to-list | 52 |
| S5 집계 상태 | tightness·heat, 유동성 지수 | 16 |
| F1 / F2 / F3 | 정의·구축 39 / 측정 쟁점 26 / 선행성·관계 83 | |
| 시장 | MLS 53 / 비MLS 포털·중개 87 / 경매 4 / 복수 4 | |

**왜 이렇게 나누나**: 탐색–매칭 이론은 거래 사슬의 상류(S1·S2)가 하류(S3·S4)보다 먼저 움직인다고 말한다. 이 리뷰의 핵심 표는 지표를 단계 순으로 놓고 보고된 선행 길이를 비교한다. 그래서 `stage`가 틀리면 핵심 표가 틀린다. 대안 비교는 `review/framework_alternatives.md`.

## 4. 순서 — 왜 한국 논문부터인가

| 주 | 무엇 | 이유 |
|---|---|---|
| **W1** (10/19~23) | **파일럿**: 8명 전원이 같은 논문 p023(서울 아파트 DOM 결정요인, 주택연구 2019)을 정리 | 8개 정리를 나란히 놓으면 양식을 서로 다르게 읽는 곳이 바로 보인다. 원석이 차이를 정리해 W2 회의에서 맞춘다 |
| **W2~W5** | 한국 관련 논문 26편 | ① 언어 부담 없이 양식에 익숙해진다 ② KCI에서 원문이 바로 나와 도서관 대기가 없다 ③ 한국(비MLS) 시장은 이 리뷰의 차별점(RQ5)이라 초반 결과로 국내 학회 발표가 가능하다 |
| **W5~W20** | 영문 논문, 단계 순 S3 매칭 → S2 공급·호가 → S5 집계 → S4 체결 → S1 수요 | 단계별로 몰아서 하면 한 단계가 끝날 때마다 표 초안을 쓸 수 있다. S3을 먼저 하는 것은 TOM 정의·측정 쟁점이 양식에서 가장 어려운 칸이라 일찍 익혀야 하기 때문 |

경제학 상위 학술지(AER·JPE·REStud·QJE·JF·RFS·IER·JUE 등) 논문은 그 주의 석·박사에게 먼저 간다.

파일럿 p023의 원문을 KCI에서 받을 수 없으면 같은 주제의 p025(아파트 특성과 DOM, 2019)로 바꾸고, 배정표를 `python3 scripts/assign.py --pilot p025 --out students/assignments.csv`로 다시 만든다.

## 7. 접수 기준 (원석이 금요일에 체크)

- 0절 서지 완전(저자 전원·연도·제목·학술지·권호·쪽·DOI) + 분류 코드 확인
- 2절 지표 표: 정의가 따옴표 안 원문 + 쪽수. 시작·종료 사건, 미거래·철회, 재등록 칸(해당 없으면 NA, 모르면 NR)
- 4절 결과 표: 방향·크기·선행 시차·쪽수 분리
- 5절 저자 한계 + 남긴 것, 8절 질 평가(해당 없는 항목은 NA)
- 추측으로 채운 칸 없음. 짝 점검에서 발견되면 전체 반려
- AI를 썼으면 `students/ai_use_log.md`에 기록
