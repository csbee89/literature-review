# 논문 정리 안내 (학생용)

## 매주 과제
- 과제는 **긴 정리 1편** 또는 **짧은 정리 4편** 중 하나다. 어느 쪽인지는 배정표의 '깊이' 칸에 적혀 있다.
- 둘 다 약 2시간 걸린다. W1~W5는 매주 과제 1개, W6부터는 매주 과제 2개다.
- 금요일까지 원석에게 낸다. 파일 이름은 `W05_이름_p012.md`처럼 주차·이름·논문 번호로 붙인다.

## 모든 정리에 공통인 규칙 다섯 가지
1. **정의는 원문을 그대로 옮긴다.** 따옴표 안에 저자 문장을 그대로 넣고 쪽수를 붙인다. 예: "the number of days between listing and sale" (p. 7)
2. **결과는 표에서 읽는다.** 계수·유의수준·시차를 표 번호와 쪽수와 함께 적는다. 저자의 결론 문장과 표가 다르면 둘 다 적는다.
3. **모르면 비워 두지 말고 NR, 해당 없으면 NA**라고 쓴다. 추측해서 채우면 짝 점검에서 전체 반려된다.
4. **분류 코드를 확인한다.** 배정표의 단계(S1~S5)·기능(F1~F3)·시장 코드가 맞는지 보고, 다르면 고친 코드와 이유를 한 줄 적는다.
5. **AI를 썼으면 기록한다.** `students/ai_use_log.md`에 날짜·용도를 한 줄 적는다. 번역 보조는 괜찮지만, 정의와 수치는 반드시 원문에서 직접 확인한다.

## 긴 정리 (1편, 약 2시간) — 양식 `templates/one_pager_template.md`
읽는 순서: 초록 → 자료·방법 절 → 결과 표 → 결론. 문헌고찰 절은 훑기만 한다.

| 절 | 무엇을 쓰나 |
|---|---|
| 0. 서지 | 저자 전원, 연도, 제목, 학술지 권(호):쪽, DOI, 분류 코드 확인 |
| 1. 한 줄 요약 | "[자료]로 [지표]를 [방법]으로 측정해 [결과]를 보였다." |
| 2. 지표 정의 표 | 지표마다 한 줄. 정의 원문과 쪽수, 단위, 시작·종료 사건(예: 매물 등록일 → 계약일), 팔리지 않은 매물·철회 매물 처리, 재등록 처리 |
| 3. 자료와 방법 | 국가·지역·기간, 자료원(MLS·포털·실거래 신고 등), 관측치 수, 방법 |
| 4. 결과 표 | 무엇이 무엇에 어떤 방향으로 얼마나(계수와 쪽수), 몇 개월 앞서는지, 어떤 검정으로 |
| 5. 한계와 남긴 것 | 저자가 밝힌 한계 2문장, 이 논문이 다루지 않은 것 |
| 6. 한국 함의 | 한 문장 |
| 8. 질 평가 | 6항목 각 0·1·2점, 해당 없으면 NA |

예시: 한국 논문 `examples/example_Ma2021_p115.md`, 영문 논문 `examples/example_Famiglietti2020.md`.

## 짧은 정리 (4편, 각 30분) — 양식 `templates/short_form.md`
거래량·심리·검색량과 가격의 관계를 VAR나 그랜저 검정으로 본 논문들이다. 지표 정의나 측정 문제는 거의 없으므로, **무엇이 무엇을 몇 개월 앞서는지**만 정확히 적는다.

| 절 | 무엇을 쓰나 |
|---|---|
| 0. 서지 | 저자, 연도, 제목, 학술지, DOI, 분류 코드 |
| 1. 지표 | 정의 원문과 쪽수 한 줄, 가공 방법(누적·로그·차분·추세 제거), 자료원과 기준(신고·등기 등) |
| 2. 자료와 방법 | 지역, 기간·주기, 방법, 시차 선택 기준 — 한 줄 |
| 3. 결과 | 방향(예: 거래량 → 가격), 유의 여부(표·쪽), 선행 시차(숫자와 단위), 검정, 지역별 차이 |
| 4. 질 평가 | q1·q3·q4·q5·q6 각 0·1·2점 |

예시: 같은 논문을 짧게 정리한 `examples/example_Ma2021_p115_short.md`. 긴 정리와 나란히 보면 무엇을 빼는지 보인다.

## 원석이 금요일에 보는 것
- 정의에 따옴표와 쪽수가 있는가
- 결과에 숫자·단위·쪽수가 있는가
- 빈칸 없이 NR·NA로 표시했는가
- 분류 코드를 확인했는가
