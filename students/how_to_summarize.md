# 논문 정리 안내 (학생용, v11 — 2026-10-13)

청년 주거경로 리뷰와 같은 방식이다. **워드 1쪽 + 구글시트 행**을 낸다.

## 매주
- **매주 수요일 모임**에서 다음 논문을 받는다(원석이 원문을 단톡방·드라이브에 올림) → **다음 모임 전날 화요일 18:00**까지 제출.
- 첫 논문만 **10/19(월)** 미리 받고 **10/27(화) 18:00** 마감, **첫 모임 10/28(수)**.
- W1~W5(마감 10/27~11/24)는 1편, W6부터 2편. 내 논문은 `students/schedule_by_person.md`.
- 파일 이름: `W01_이름_p023.docx`. 워드는 구글 드라이브 「주택시장 유동성 지표 리뷰/09_제출(워드)/W01…」 주차 폴더에 올린다. 시트는 드라이브 「05_추출시트」(공용 구글시트)에 직접 행을 추가한다.

## 내는 것 두 가지
### 1. 워드 1쪽 — 양식 `handover/word/논문정리_양식_v1.docx`
| 칸 | 쓰는 것 |
|---|---|
| 서지 | 저자 (연도). 제목. 학술지 권(호), 쪽. DOI |
| 1. 분류 | 단계(S1~S5)·기능(F1~F3)·시장(MLS/비MLS/경매) — 배정표 값이 맞는지 보고, 다르면 고치고 이유 한 줄. 지표 이름과 정의, 결과, 국가·자료, 표본, 분석 방법을 한 줄씩 (쪽) |
| 2. 요약 | 4~6문장. 무엇을 물었나 → 어떤 자료 → 어떤 방법 → 무엇을 찾았나(핵심 숫자 한두 개) → 저자 결론. 문장마다 쪽수 |
| 3. 저자가 적은 한계 | 논문에 적힌 한계 1~3개. 없으면 「적힌 한계 없음」 |
| 4. 읽으면서 막힌 것 | 이해 안 된 표, 숫자가 안 맞는 곳, 애매한 용어, 저자 문장과 표가 다른 곳. 비워 두지 않는다 |

### 2. 구글시트 — 양식 `handover/유동성리뷰_추출시트_양식.xlsx`
지표마다 1행. 지표 정의 원문, 시작·종료 사건, 안 팔린·철회 매물 처리, 재등록 처리, 가공, 자료 기준(신고·등기·호가), 관측 수, 결과 크기, 선행 시차, 질 평가 6항목. 칸마다 무엇을 쓰는지는 '칸 설명' 시트에 있다.

## 규칙 다섯 가지 (청년 리뷰와 같음)
1. **논문에 있는 것만 쓴다.** 없으면 「보고 안 됨」, 해당 없으면 「해당 없음」. 빈칸으로 두지 않는다.
2. **칸마다 쪽수.** 괄호 안에 (57)처럼.
3. **숫자는 원문 그대로.** 반올림하거나 바꿔 쓰지 않는다. 직접 계산한 값은 비고에 '계산'이라고 적는다.
4. **정의는 따옴표로 원문 그대로.** 번역하지 않는다(워드 요약은 우리말로).
5. **AI를 썼으면 `students/ai_use_log.md`에 한 줄.** 번역 보조는 괜찮다. 정의·숫자는 반드시 원문에서 직접 확인한다.

## 예시 (배정되지 않는 논문)
- 한국 논문: `handover/word/예시_p115_마승렬2021.docx` — 거래량과 가격의 선후행(시계열). 대부분의 한국 논문이 이 모양이다. 시트의 기간·절단 칸은 「해당 없음」이 많다.
- 영문 논문: `handover/word/예시_p033_Liu2024.docx` — 매물 시간(TOM)과 매물 결과(MLS 자료). 매물 단위 논문은 시트 칸이 거의 다 찬다.
- 시트 예시는 양식 파일의 회색 두 행.
