# Codex 지시서: 유동성 리뷰 원문 PDF 내려받기 (2026-10-20)

**누가**: 연구책임자 PC의 Codex (가천대 네트워크·도서관 인증이 되는 컴퓨터).
**무엇을**: `download_list_68.csv`의 68편을 학술지 **게재본 PDF**로 내려받는다. 체계적 문헌고찰(연구책임자 본인 연구용) 원문 확보이며, 학교 구독으로 정당하게 접근 가능한 것만 받는다.

## 규칙
1. **한 편씩, 천천히.** 출판사는 대량 자동 다운로드를 금지하고 학교 IP를 차단할 수 있다. 다운로드 사이에 **최소 30~60초** 쉬고, 같은 출판사 연속 요청을 피한다(목록을 출판사가 섞이게 처리). 차단·CAPTCHA·"unusual activity" 화면이 나오면 그 출판사는 즉시 중단하고 실패로 기록한다. 우회 시도 금지.
2. **경로**: `https://doi.org/<DOI>` → 출판사 페이지 → PDF. 학교 인증이 필요하면 가천대 도서관 프록시/로그인을 쓴다. Sci-Hub 등 불법 사이트 금지.
3. **게재본만.** 워킹페이퍼·preprint·accepted manuscript는 받지 않는다(받았다면 `*_WP.pdf`로 따로 두고 실패로 기록). p030은 이미 워킹페이퍼판이 있으므로 게재본(Bulletin of Economic Research, DOI 10.1111/boer.12284)만 필요.
4. **확인**: 받은 PDF의 첫 쪽 제목이 CSV `title`과 같은지, 파일이 `%PDF`로 시작하는지 확인. 다르면 지운다.
5. **이름**: `pXXX.pdf` (예: `p037.pdf`).
6. **저장 위치**: 이 PC에 구글 드라이브 데스크톱이 있으면 `내 드라이브/주택시장 유동성 지표 리뷰/원문/`에 바로 저장(가천 계정 sbchoi@gachon.ac.kr). 없으면 `다운로드/유동성리뷰_원문/`에 저장하고 끝에 알린다.
7. **보고**: `download_report.csv`(pid, 결과 성공/실패, 실패 이유, 저장 경로)를 같은 폴더에 남긴다. 실패 이유 예: 학교 구독 없음, 차단, 게재본 아님, 제목 불일치.

## 우선순위
`needed_by`가 이른 순서(W6 → W7 → … → W12). 가장 급한 것: p037(11/25), W7 10편(12/2).

- 비밀번호·쿠키를 파일에 쓰지 않는다.
