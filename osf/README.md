# OSF 사전등록 — 교수님이 하실 일 (15분)

1. https://osf.io 에서 계정 생성(기관 이메일). 
2. 오른쪽 위 **Create new project** → 제목 `Housing market liquidity indicators: a systematic review (protocol)` → Create.
3. 프로젝트 화면에서 **Files**에 아래 세 파일을 끌어다 올린다: `preregistration.md`, `synthesis_set_148.csv`, `../protocol/01_protocol.md`.
4. 상단 **Registrations** → **New registration** → 양식은 **OSF Preregistration** 선택.
5. 각 칸에 `preregistration.md`의 같은 제목 절을 복사해 붙인다(칸 제목이 영어로 같다).
6. 마지막 단계에서 **Make registration public immediately** 선택 → Register. (Embargo를 걸면 심사 때 보여 줄 수 없다.)
7. 등록이 끝나면 주소가 `https://osf.io/xxxxx` 꼴로 나온다. 그 다섯 글자를 저에게 보내 주시면 프로토콜 §1과 논문 방법 절에 넣는다.

등록 뒤에는 내용을 고칠 수 없다. 변경은 프로토콜 §13에 적고, 필요하면 "Update registration"으로 새 버전을 덧붙인다.
